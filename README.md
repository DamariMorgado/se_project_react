# WTWR (What to Wear?)

## About the Project

WTWR is a React application that recommends clothing based on the current weather at your selected location. The app fetches real-time weather data from the OpenWeather API and displays clothing suggestions filtered by the current temperature.

## Functionality

- Displays current temperature and location in the header using live weather data
- Filters clothing card recommendations based on current weather conditions (hot, warm, or cold)
- Weather card shows a background image that varies based on time of day and weather conditions
- Users can open a "New Garment" modal to add clothing items
- Clicking a clothing card opens an image preview modal
- Both modals can be closed via the close button, clicking the overlay, or pressing Escape

## Technologies & Techniques

- React (functional components, hooks: useState, useEffect)
- Vite build tool
- OpenWeather API
- BEM methodology for CSS class naming
- CSS Flexbox for layout
- Responsive design
